# ตารางแพทย์ออกตรวจ · โรงพยาบาลพริ้นซ์ ลำพูน

เว็บแอพสำหรับดูตารางแพทย์ออกตรวจ (ดูอย่างเดียว ไม่ต้องลงชื่อเข้าใช้) ดึงข้อมูลจาก Google Sheets ของสำนักเลขานุการ

- สำนักเลขานุการ **แก้ไขที่ Google Sheets** ที่เดียว
- ทุกคนเปิดดูผ่านลิงก์ Vercel ได้ ทั้งมือถือและคอมพิวเตอร์ ติดตั้งเป็นไอคอนบนหน้าจอได้
- แอพดึงข้อมูลใหม่ทุก 60 วินาที (Google อาจใช้เวลาไม่กี่นาทีหลังแก้ไขจึงอัปเดตลิงก์ที่เผยแพร่)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `config.js` | **ไฟล์เดียวที่ต้องแก้** ใส่ลิงก์ CSV จาก Google Sheets และเบอร์โทร |
| `index.html`, `app.js` | ตัวแอพ |
| `data/sample.json` | ข้อมูลตัวอย่าง ต.ค. 2569 (ใช้เมื่อยังไม่ได้ใส่ลิงก์) |
| `manifest.webmanifest`, `icon-*.png`, `logo.png` | ไอคอนและการติดตั้งเป็นแอพ |
| `vercel.json` | ตั้งค่า Vercel |

## ขั้นที่ 1: เอาลิงก์ CSV จาก Google Sheets

1. เปิดไฟล์ Google Sheets ตารางแพทย์ออกตรวจ
2. ไฟล์ > แชร์ > เผยแพร่ไปยังเว็บ
3. เลือกชีต **ตารางออกตรวจ** และรูปแบบ **ค่าที่คั่นด้วยจุลภาค (.csv)** แล้วกดเผยแพร่ คัดลอกลิงก์
4. ทำซ้ำกับชีต **ข้อมูลรายวัน**
5. ติ๊ก "เผยแพร่ซ้ำโดยอัตโนมัติเมื่อมีการเปลี่ยนแปลง"
6. วางลิงก์ทั้งสองใน `config.js`

## ขั้นที่ 2: Deploy ขึ้น Vercel

### วิธี A: ผ่าน GitHub (ไม่ต้องใช้คำสั่ง แนะนำ)
1. สมัคร/เข้าสู่ระบบ github.com → New repository → ตั้งชื่อ เช่น `prince-opd-schedule` → Create
2. กด "uploading an existing file" แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ขึ้นไป → Commit changes
3. เข้า vercel.com → เข้าสู่ระบบด้วย GitHub → Add New… > Project → เลือก repository → Deploy
   (Framework Preset: Other · ไม่ต้องตั้ง Build Command)
4. ได้ลิงก์ เช่น `prince-opd-schedule.vercel.app`
5. ต่อไปแก้ `config.js` บน GitHub (ไอคอนดินสอ) → Commit แล้ว Vercel จะอัปเดตเว็บให้อัตโนมัติ

### วิธี B: ผ่าน Vercel CLI (สำหรับฝ่าย IT)
```bash
npm i -g vercel
cd prince-opd-schedule
vercel          # ครั้งแรก: ล็อกอินและตั้งค่าโปรเจกต์
vercel --prod   # deploy จริง
```

## ขั้นที่ 3 (ไม่บังคับ): โดเมนของโรงพยาบาล
Vercel > Project > Settings > Domains > เพิ่ม เช่น `schedule.<โดเมนโรงพยาบาล>` แล้วให้ IT ตั้งค่า DNS ตามที่ Vercel แจ้ง

## ข้อควรรู้
- ข้อมูลในชีตที่เผยแพร่เป็น **สาธารณะ** ใครมีลิงก์ก็เห็นได้ ใช้กับตารางแพทย์เท่านั้น ห้ามใส่ข้อมูลผู้ป่วย
- ห้ามเปลี่ยนชื่อหัวคอลัมน์ `วันที่` `แพทย์` `สาขา` `เวลา` `ป้ายวันหยุด` `หมายเหตุ`
- วันที่ในชีตใช้รูปแบบ วัน/เดือน/ปี (ค.ศ. หรือ พ.ศ. ได้ทั้งคู่)
- แผน Hobby ของ Vercel สำหรับการใช้งานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ การใช้ในนามโรงพยาบาลควรตรวจสอบเงื่อนไขกับ IT ว่าต้องใช้แผน Pro หรือไม่
